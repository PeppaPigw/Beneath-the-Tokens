# Beneath the Tokens

## AI Infrastructure from first principles

AI infrastructure is the discipline of turning algorithms into dependable, observable, economical systems that can train, evaluate, serve, and improve models under real constraints.

This book follows one causal question:

> Given data, a model, a workload, and a reliability target, what must the system do, where does it spend time and money, how can it fail, and how do we prove that it works?

The route moves from Linux and performance fundamentals through distributed training, inference serving, data systems, orchestration, observability, security, and frontier-scale design.

## How to read

Each chapter has seven layers:

1. **Mental model** — the smallest useful explanation
2. **First principles** — equations, invariants, and resource bounds
3. **Mechanism** — how the system actually executes
4. **Code** — a small implementation and a production implementation reading
5. **Experiment** — a measurable lab with expected observations
6. **Failure clinic** — symptoms, causes, and discriminating tests
7. **Mastery check** — six questions that test causal understanding

Read sequentially through Part I–III. Part IV–VI are specialization and architecture tracks; return to them when a project demands them.
